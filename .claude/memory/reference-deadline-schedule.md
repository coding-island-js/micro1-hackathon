# The deadline and the three-day shape

**Mon 31 Aug 2026, 11:00 AM Pacific.** Repo started Fri 28 Aug 2026.

| Day | Job | Done means |
|---|---|---|
| **Fri 28** | validate the hypothesis | frozen benchmark + baseline result + one advanced run + a real measured comparison |
| **Sat 29** | improve, and prove each improvement | changelog rows with evidence; benchmark expanded toward 10+; costs and runtimes tracked |
| **Sun 30** | produce the submission | architecture frozen early; final eval, README, reproduction guide, trajectories, **video finished** |
| **Mon 31 am** | buffer only | clean-environment reproduction test, fix blockers, upload, submit |

**Why it matters:** the video is the item that cannot be compressed, and the clean-environment
test is the item most likely to fail late. Both are scheduled a full day before the deadline on
purpose. No feature work is planned for Monday.

**How to apply:** if Friday's comparison does not show a real difference, the correct Saturday
move is to change the experiment, not to keep tuning a workflow that is not moving the number.
A negative result written up honestly still scores under Measured Improvement and Hot Take.
