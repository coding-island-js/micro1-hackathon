# Rubric weights — where the 100 points actually are

From the official PDF, §"How judging works", 2026-08-28.

| Criterion | Pts |
|---|---|
| Agent Solution & Engineering | **30** |
| End to End Quality | **20** |
| Problem & User Value | 15 |
| Measured Improvement | 15 |
| Reproducibility | 15 |
| Hot Take / Insights | 5 |

**What the shape means:**
- **50 of 100 are engineering + finish.** Not novelty, not the size of the idea.
- End-to-End Quality (20) is scored on whether the output "reads as clearly AI generated". It is
  a *writing and polish* line, and it is worth more than the measured improvement.
- Measured Improvement is only 15, but it gates credibility on the other 85 — a shaky number
  makes the engineering claim unverifiable.
- Hot Take is 5 points for one paragraph. Cheapest points in the rubric; never skipped.
- Reproducibility (15) is won or lost by a judge on a clean machine, so it must be *tested* on
  one, not asserted.
